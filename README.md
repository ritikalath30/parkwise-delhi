# ParkWise Delhi

Build a website called ParkWise GeoAI.

It should help people visiting crowded areas in Delhi find restaurants and cafes that have convenient authorised parking nearby.

Make the website modern, attractive and easy to use.

I want four main screens:

1. Search screen: Let users enter their destination, arrival time, parking budget and maximum walking distance. Use Hauz Khas Village as the example location.

2. Map screen: Show restaurants and nearby authorised parking locations on an interactive map. Use different markers for parking facilities and restaurants.

3. AI recommendations: Recommend the top three restaurants based on estimated parking availability, parking charges, walking distance and expected search time. Explain why each is recommended.

4. Final screen: Let users select a restaurant and see the recommended parking facility, estimated cost and walking distance.

Important:

- Use sample data for the prototype.

- Clearly mention that parking availability is simulated, not live.

- Do not recommend illegal or unverified parking.

- Make the map interactive.

- Make all buttons and filters functional.

- Use AI to explain recommendations.

- Do not require users to log in.

- Make the website mobile-friendly.

Build a complete working user journey, not just a visual design.

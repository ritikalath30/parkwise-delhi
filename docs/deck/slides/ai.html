PRODUCT DECISIONWHAT I CHOSEWHY
Where the model runsOn-device MiniLM (in the browser); cloud LLM (Claude) wired as optional upgrade₹0 per query, no API key exposed, user text never leaves the phone
What AI may decideOnly user intent, never places, prices or hoursNo hallucinated car parks; facts come from map data
Human in the loopShows what it understood + confidence (e.g. "elderly parents" → short walk, 83%); editableBuilds trust; errors are visible and correctable
Evaluation46 automated tests incl. typos and intents; live metric: % requests needing no editTarget ≥ 80% no-edit rate in pilot
Geospatial AI (built)Radius search over 3,281 restaurants / 934 lots; legality classification from OSM tags; opening-hours parsing across midnight; OSRM road-network walking matrix; typo-tolerant geocodingFacts and distances are computed, not guessed
Computer vision (future)Vehicle detection (YOLO-class model) on ≤0.5 m satellite or lot CCTV to estimate occupancy; spatio-temporal demand forecasting from real counts"Image estimate" slot already in the product; not live: needs licensed imagery and a validated model
